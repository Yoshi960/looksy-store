# LOOKSY STORE

Telegram-бот и мини-апп магазина одежды. Работает бесплатно:

- **мини-апп** — GitHub Pages (`web/`);
- **база, фото, бот** — Supabase: Postgres, хранилище `uploads`, функция `api` (`supabase/`).

Любое изменение в ветке `main` само публикуется: GitHub Actions обновляет базу, функцию и мини-апп.

## Что умеет

**Покупатель:** разделы «Женщинам / Мужчинам», категории, поиск, фильтры, «Выбор недели», карточка товара с отзывами и «как сидит», избранное, заказ через Telegram или телефон. Тема — как в Telegram.

**Админка** (значок в шапке, видна только ID из `ADMIN_IDS`): товары с фото, ценой, закупкой и маржой, продвижение (хит / быстро продать / высокая маржа), категории, заказы со статусами, модерация отзывов, статистика по источникам и прибыль.

**Бот:** приветствие с кнопкой каталога, заказы приходят админам, сообщения из избранного о снижении цены и возврате в наличие, просьба оставить отзыв после статуса «Получен».

Ссылки для каналов: `t.me/ИМЯ_БОТА?start=tiktok`, `?start=avito`, `?start=baraholka` — источник виден в статистике. Команда `/id` показывает Telegram ID.

## Первый запуск

1. **Supabase.** Создать проект на supabase.com (регион — ближайший к России, например Frankfurt). Сохранить пароль базы.
2. **Ключи в GitHub:** репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Где взять |
|---|---|
| `SUPABASE_PROJECT_REF` | Supabase → Project Settings → General → Reference ID |
| `SUPABASE_DB_PASSWORD` | пароль базы из шага 1 |
| `SUPABASE_ACCESS_TOKEN` | supabase.com → Account → Access Tokens → Generate |
| `BOT_TOKEN` | @BotFather |
| `ADMIN_IDS` | ваши Telegram ID через запятую |
| `SETUP_KEY` | любая длинная случайная строка |

3. **GitHub Pages:** Settings → Pages → Source: **GitHub Actions**.
4. **Запуск:** Actions → «Публикация» → Run workflow. Через пару минут мини-апп откроется по адресу `https://<ник>.github.io/looksy-store/`, а у бота появится кнопка «Каталог».

Бесплатный проект Supabase засыпает после недели без запросов — workflow «Не давать базе уснуть» открывает каталог раз в день.
